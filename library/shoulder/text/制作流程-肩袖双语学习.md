# 肩袖双语学习材料：制作与维护流程

更新：2026-10-06。当前输出包含 6 个章节、17 张可编辑 SVG、英文完整叙述与中文对应翻译，以及经过模型清单核对的 3D 跳转。

## 1. 内容顺序与表达规则

| 章节 | 学习任务 | 当前实现 |
| --- | --- | --- |
| 01 Anatomy | 辨认结构和起止点 | 四块肩袖肌分别标 O（Origin，起点）与 I（Insertion，止点），附完整走行句 |
| 02 Innervation | 把神经路线放回人体解剖 | 肩胛上神经、腋神经实体解剖示意；流程图作补充；区分 C/T、椎骨与脊神经 |
| 03 Movement | 连接附着、作用线与运动 | 起止点对照、力偶、肩肱节律与阶段性完整说明 |
| 04 Clinical anatomy | 将检查与局部解剖对照 | 英中术语、检查表、重排后的临床图和穴位叠加图 |
| 05 Review | 简记与完整专业表达并行 | 保留三句原口诀，提供英文完整叙述、中文翻译和四组完整问答 |
| 06 Paper reading | 理解研究问题、效应量及方法 | 英文段落后接中文；方法学术语单独分项；保留证据范围 |

- 图示和专业名称均先英文、后中文。连续描述使用完整英文句子，再给对应中文，避免把中文句子的几个名词换成英文就当作英语表达。
- 肌肉描述采用：**The [muscle] originates from [origin], passes [direction or relation], and inserts onto [insertion].** 然后说明神经支配、动作与稳定作用。
- `Origin → Insertion` 是附着顺序。图中的虚线 O→I 与实线受力箭头分开，不能把两者当成同一方向。
- 起止点为示意区域；未绘出的骨面不能随意加点。上斜方肌的锁骨止点等未显示部分，在图内独立文字区说明。
- `C = Cervical（颈部）`，`T = Thoracic（胸部）`。`C5 vertebra` 指第5颈椎；神经支配的 `C5–C6` 指贡献纤维的颈神经节段。图中分别标注骨与神经。
- 制作说明、AI 提示词和方法记录放在本文件；学习正文保留知识、图示、英语表达、练习和来源。

## 2. 权威来源与证据边界

肌肉附着优先核对解剖教材/出版方资料，神经走行核对大学解剖课程与解剖研究。来源位于各节正文，机器可读记录在 `library/shoulder/text/data/`。

- [Elsevier：Supraspinatus](https://www.elsevier.com/resources/anatomy/muscular-system/muscles-of-upper-limb/supraspinatus-muscle/21166)
- [Gray’s：肩部肌肉与附着](https://elsevier-elibrary.com/contents/fullcontent/58750/epubcontent_v2/OEBPS/B9780443066849500548.htm)
- [Elsevier：Subscapularis](https://www.elsevier.com/resources/anatomy/muscular-system/muscles-of-upper-limb/subscapularis-muscle/16597)
- [University of Utah：上肢解剖](https://anatomy.med.utah.edu/diganat/PT/2014_lecture/PT_syllabus_2014_sm.pdf)
- [NCBI：Cervical nerves](https://www.ncbi.nlm.nih.gov/books/NBK538136/)

论文阅读沿用 [scientific-critical-thinking / SKILL.md](https://github.com/K-Dense-AI/scientific-agent-skills/blob/main/skills/scientific-critical-thinking/SKILL.md) v1.5 的方法：先确定研究问题和设计，再区分主要/次要结局、效应量/区间、偏倚与适用范围。本次读取后应用，没有全局安装。

Skill 归属：Kassis T, Agarwal V, He Y, Patel D, Brueckner AM. *Scientific Agent Skills: A Library of Procedural Knowledge for Research Agents*. 2026. [arXiv:2609.00065](https://doi.org/10.48550/arXiv.2609.00065)。

该试验目前核对的是 [结果摘要](https://pubmed.ncbi.nlm.nih.gov/41476428/) 与 [公开研究方案](https://www.rbf-bjpt.org.br/en-download-pdf-S1413355518307871)。结果全文、实际缺失数据处理、多重比较、不良事件、OR参照组及注册历史尚未完整核验；正文明确保留这些边界。130 人为计划招募数，121 人为结果报告数，两者之差不作为失访人数。

当前最终输出：`2026-10-06-肩袖-阅读优化版.html`、同名 `.md`、`library/shoulder/3d/public/reading.html` 与本地服务使用的 `dist/reading.html`。

修改时先编辑章节源稿和 SVG，再运行构建；不要只改单个输出副本。HTML 和 Markdown 是分别审阅的源稿，两者内容调整需要同步。四肌数据若有调整，也要同步对应章节源稿。

## 4. 3D 对应规则

| 名称 | 实际跳转参数 |
| --- | --- |
| Supraspinatus | `?term=supraspinatus` |
| Infraspinatus | `?term=infraspinatus` |
| Teres minor | `?term=teres-minor` |
| Subscapularis | `?term=subscapularis` |
| Deltoid | `?term=deltoid`（集合） |
| Anterior deltoid | `?term=clavicular-part` |
| Middle deltoid | `?term=acromial-part` |
| Posterior deltoid | `?term=posterior-deltoid` |
| Humerus / Scapula / Clavicle | `?term=humerus` / `scapula` / `clavicle` |
| Lesser tubercle 等骨标 | 采用 `src/*-landmarks.json` 中的实际 ID |

链接基址为 `http://127.0.0.1:5178/`，使独立 HTML、Markdown 和站内阅读页都可进入同一个模型页面。已有穴位跳转使用对应 `?point=`。

当前 atlas 没有 Trapezius、Serratus anterior、Teres major 的网格。它们保留解剖图与文字，并注明模型缺项，不链接到另一块肌肉冒充目标。模型文件、穴位坐标与语音文件没有为这次阅读改版而改动。

骨标 URL 的初始化已补齐：已有词条优先，其次检查 `landmarkById`，最后处理穴位参数。这样 `?term=lesser-tubercle` 等新骨标会选中目标，而不再默默落回初始肌肉。

## 5. 构建与检查

在“肩袖”目录运行：

```sh
python3 library/shoulder/text/build-reading.py
```

生成器会检查：六个章节、所有图示占位符、SVG XML有效性、网页ID唯一性、Markdown图片路径、3D term是否存在于词库或骨标清单。它同时更新独立HTML、Markdown、public与dist阅读页。

若修改了3D应用代码，还需运行：

```sh
cd library/shoulder/3d
pnpm build
```

最后进行浏览器检查：

1. 在实际阅读宽度检查四张起止点图、两张神经实体图、臂丛图、临床图与穴位图。
2. 展开流程图和肌肉时间轴，检查文字不超出SVG边界、不与其他标注重叠；宽图使用横向滚动，不强行压缩字体。
3. 检查每组完整英文之后都有对应中文；四组问答展开后都包含完整答案。
4. 对照记录核对 SPADI、PASS、OR、CI、时间点和单位，保护正式论文标题、DOI和来源文件名。
5. 点击代表性肌肉与新增骨标链接，等待模型加载，核对实际选中名称；其余链接用词库与模型对象清单核验。
6. 保留截图和构建记录，确认 `public/reading.html` 与 `dist/reading.html` 内容一致。

本轮已完成：构建及 TypeScript 检查；17张图的显示文字边界/相互重叠检查；Supraspinatus与Lesser tubercle的实际跳转；已支持肌肉的左右侧模型对象核对。论文全文未取得等证据缺项仍按第2节保留。
