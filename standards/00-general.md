# 第 0 层 · 通用原则

适用于所有内容方向。方向规范可以加严，不能放宽。

| 编号 | 规则 | 来源 |
| --- | --- | --- |
| G-01 | **English first, Chinese second.** 专业名称、图标、标题、问题、答案、方法学术语都英文在前、中文在后。连续描述先写完整英文句子，再写完整中文翻译；不能用中文句子里夹几个英文名词代替英语表达。 | CLAUDE.md §4；QUALITY_RULES 1 |
| G-02 | **只用真正打开过的来源。** 网址写进正文或数据的 `sources`；搜索摘要不算来源；打不开的网页不用别的方式绕过；第三方图片和模型确认许可。 | 每日生成任务；CLAUDE.md §4 |
| G-03 | **如实标注。** 不确定处在正文写明；未核验项列进制作记录；不虚构结果、审核人、日期或通过标记；草稿不称为完成。 | QUALITY_RULES 9；ADDING_A_TOPIC §4 |
| G-04 | **正文只放学习内容。** 知识、图示、英语表达、练习和来源；不写 AI 提示词、制作过程、“下面我们来看”一类过渡语。制作说明放制作记录。 | dpt-reading-pack §1；CLAUDE.md §4 |
| G-05 | **读者。** gui：已被 USC DPT 录取，有中医背景。不用公共卫生视角。 | dpt-reading-pack；每日任务 |
| G-06 | **质量优先于速度。** 用户拒绝过“图片 读音 整体质量都不行”的版本；宁可多花时间也不降低质量。 | 每日生成任务 |
| G-07 | **检查不过就改内容。** 不为了通过而修改检查本身；自动检查只证明结构，不证明事实正确或版面可读。 | 每日生成任务；QUALITY_RULES 8 |
| G-08 | **源稿唯一。** 只改源文件（content.json、章节源稿、SVG、data），由构建生成输出；不在生成的副本上改。 | dpt-reading-pack §8；CLAUDE.md §3 |
| G-09 | **保留既有资产。** 现有语音、音频、来源记录、模型许可、独立阅读版（reading-claude.html）未经用户新指示不替换。 | CLAUDE.md §4 |
