# 新增内容方向的骨架

以后做生理解剖以外的方向（例如药理、运动处方）时，照这里建一套第 1 层和第 3 层。第 0 层 [00-general.md](../00-general.md) 直接继承，不复制。

1. 新建 `standards/<direction>/`，放五个文件，文件名和生理解剖保持一致：

   | 文件 | 写什么 | 编号前缀 |
   | --- | --- | --- |
   | `chapters.md` | 该方向的章节模板（主模板，必要时加短版变体） | `CH-` |
   | `rules.md` | 该方向特有的写法、图示、来源、核验规则 | 自取两个字母，如 `PH-` |
   | `steps.md` | ST- 编号的四格表（解剖方向现有 ST-1 至 ST-9）：输入、输出、合格标准（引用编号） | `ST-` |
   | `checklist.md` | 自动项和人工项 | `QC-` |
   | `exemplars.md` | 用户认可的成品 | — |

2. 先用一个主题做样板，用户认可后写进 `exemplars.md`，再批量做。
3. 在 `standards/README.md` 的四层表里加一行，在 `CHANGELOG.md` 记录。
4. 方向之间不互相引用；能复用的写法若对所有方向都成立，提升到第 0 层。
