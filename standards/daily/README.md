# 每日学习规程 · Daily learning

继承 [00-general.md](../00-general.md) 和 [library/rules.md](../library/rules.md)。

用户 2026-10-08 定的分工：**知识库**（`library/`）是生成好的大内容，按部位分章；**每日学习**（`daily/`）按本规程从知识库取材，生成当天该学的东西。每日学习不另起一套知识。

## 取材规程（DL-01 至 DL-09）

| 编号 | 规则 |
| --- | --- |
| DL-01 | 【目标，尚未落实】每天的肌肉、神经、动作、穴位事实取自知识库里对应的章节 `library/<id>/`，不在每日包里另写一份。 |
| DL-02 | 【目标，尚未落实】当天计划（`daily/plan/schedule.json`）里的结构，知识库还没有对应章节时，先按 [library/steps.md](../library/steps.md) 在知识库建好或补进已有章节，再生成当天的包。 |
| DL-03 | 【目标，尚未落实】每日包的图优先复用知识库章节的 SVG；需要新画的图，同时加回该章节的 `figures/`。 |
| DL-04 | 【目标，尚未落实】每日包注明取自哪些章节（章节 id），读者能从当天内容回到完整章节。 |
| DL-05 | 每日包用下面的 CH-02 短版；质量要求与知识库相同（G-01 至 G-09、AN 系列规则）。 |
| DL-06 | 每日包的源文件在 `daily/days/<date>/`，网页在 `site/public/daily/<date>/`；发送、存档和定时由推送流程负责，不在本规范内。 |

**现状（2026-10-08）**：晚间生成任务仍是每天从头写 `content.json`，第 1、2 天的胸大肌、胸小肌、锁骨下肌、前锯肌、斜方肌和肺经穴位在知识库里还没有章节。DL-01 至 DL-04 要等推送端改流程后才能落实，由用户决定何时改。

## CH-02 短版变体（每日包：穴位 + 肌肉）

用于一次学几个穴位和几块肌肉的短内容。共用 CH-01 的前三章要求，后三章替换为：

| # | id | 标题 | 必须包含 |
| --- | --- | --- | --- |
| 01 | `muscles` | Muscles | 同 CH-01 第 01 章的肌肉卡片，加“怎么记”卡片 |
| 02 | `nerve` | Innervation | 同 CH-01 第 02 章；神经图从脊髓画起 |
| 03 | `motion` | Movement | 从拉力线讲动作，必要时讲力偶和发力顺序 |
| 04 | `acupoints` | Acupoints | 每个穴位按 AN-20 写全；穴位歌诀；易混点 |
| 05 | `review` | Review | 自测题、闪卡、肌肉和穴位汇总表 |
| 06 | `english` | English | 读音表（AN-07）；来源 |

短版的字段定义在 `daily/CONTENT_SCHEMA.md`，由每日生成流程使用；规则内容以本文件为准。
