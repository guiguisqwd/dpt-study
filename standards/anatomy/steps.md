# 第 3 层 · 生理解剖制作步骤

每一步写成同样的四格。调整某一步时只改那一行；合格标准只引用规则编号，不重写规则。

| 步骤 | 输入 | 输出 | 合格标准 |
| --- | --- | --- | --- |
| ST-1 选题 | 学习计划或用户指定的主题 | 主题数据中的结构清单（肌肉、神经、骨性标志、穴位、论文） | 每个结构都能放进 CH-01 或 CH-02 的某一章 |
| ST-2 查证 | 结构清单 | 起止点、走行、神经、动作、穴位数据；核对记录 | G-02、AN-02、AN-20、AN-50、AN-51；未核验项已列出（G-03） |
| ST-3 写作 | 主题数据 + 章节模板 | 六章正文（单一源稿） | CH-01/CH-02、AN-01 至 AN-07、AN-30 至 AN-35、G-04 |
| ST-4 画图 | 主题数据 + 正文 | 编号 SVG | AN-10 至 AN-17、AN-21、AN-22 |
| ST-5 核验 | 构建后的页面和 SVG | 截图、检查清单结果 | [checklist.md](./checklist.md) 自动项全过，人工项逐条有证据；G-07 |
| ST-6 定稿 | 通过核验的内容 | 成品 + 制作记录（方法、来源边界、3D 映射、未核验项） | 制作记录齐全；之后交给推送流程，本规范到此为止 |

## 文件落点

| 内容 | 新主题 | 肩袖（兼容路径） |
| --- | --- | --- |
| 主题数据 | `topics/<id>/topic.json`、`content.json` | `reading-source/data/*.json` |
| 正文 | `topics/<id>/content.json`（生成 HTML 和 Markdown） | `reading-source/sections/0N-*.html` 与 `.md` 双源稿 |
| 图示 | `topics/<id>/assets/` | `2026-10-06-肩袖-阅读优化版-资源/` |
| 制作记录 | `topics/<id>/` 下的制作记录 | `制作流程-肩袖双语学习.md`、`论文阅读核对记录.json` |

构建与校验命令见 [docs/ADDING_A_TOPIC.md](../../docs/ADDING_A_TOPIC.md)。
